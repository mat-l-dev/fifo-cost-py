# Registro de cambios / Changelog

## 0.1.0 — versión inicial en preparación / initial release in preparation

- Licencia Apache-2.0 incluida en el repositorio, sdist y wheel; metadatos SPDX explícitos.
- Motor FIFO determinista por producto y moneda, con cantidades y costos unitarios enteros.
- Eventos inmutables, secuencias explícitas y resultados con trazabilidad por capa.
- Validación estricta, errores tipados y rechazo de salidas sin stock suficiente.
- API Python y CLI JSON sin dependencias de ejecución.
- Documentación en español e inglés, ejemplos ejecutables y pruebas locales.

English: deterministic per-item/currency FIFO costing, immutable events, layer-level audit output, strict validation, typed errors, a dependency-free Python API and JSON CLI, bilingual documentation, examples, and local tests. Apache-2.0 license included in the repository and distributions, with explicit SPDX metadata.
